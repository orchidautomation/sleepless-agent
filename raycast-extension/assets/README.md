# Assets

Place the following icon files in this directory:

## Required Icons

- **extension-icon.png** (512x512px) - Main extension icon shown in the Store and preferences
- **command-icon.png** (512x512px) - Icon for Ask and Quick Ask commands
- **history-icon.png** (512x512px) - Icon for the History command

## Dark Mode Variants (Optional)

For automatic dark mode support, add `@dark` suffix variants:
- extension-icon@dark.png
- command-icon@dark.png
- history-icon@dark.png

## Recommendations

- Use PNG format with transparency
- Keep designs simple and recognizable at small sizes
- Consider using a robot/AI assistant motif for the main icon
- Use a clock icon for history
